# Trivi as Lead Funnel — Strategy for Selling Agent

## The Big Picture

litai LLC's core business: **evaluation of complex AI systems** (the serious work).

The problem: cold outreach is expensive, time-consuming, and you're busy with your main client. You need a passive funnel that attracts the right people while you focus on delivery.

The solution: **small, free, genuinely useful AI tools** that demonstrate competence and attract people who care about AI quality. Trivi is the first. More will follow.

## The Funnel

```
Free useful tool (Trivi, others)
  → User finds it helpful
    → Sees "made by litai" footer
      → Visits litai GitHub / website
        → Discovers litai does serious AI evaluation work
          → Contacts litai for consulting / evaluation project
```

This is a **credibility funnel**, not a sales funnel. You're not selling Trivi. You're using Trivi to prove "this team ships things that work."

## Why This Works

1. **Zero cost to maintain.** Static site on GitHub Pages. No servers. No bills.
2. **Self-qualifying leads.** People who use AI tools and care about quality → exactly your target audience for AI evaluation services.
3. **Compounds over time.** Each new tool adds to the portfolio. The GitHub org becomes a showcase.
4. **No cold outreach needed for this channel.** The tools find their audience through word-of-mouth, SEO, and Gumroad discovery.

## What the Selling Agent Should Know

### About Trivi
- Free PWA for quick tasks: translation, explanations, commands, Q&A
- Works on any device (phone, desktop) — installs like a native app
- User brings their own API keys (Gemini free tier)
- No account needed, no data collected, no server
- Special care for Ukrainian language (anti-Russian guardrails)
- Built by litai LLC

### About the Funnel Role
- Trivi is **not the product being sold.** It's a free tool that demonstrates execution quality.
- The product is **litai's AI evaluation expertise** — Trivi shows "we build things that work correctly"
- When promoting Trivi, always link back to litai's main presence
- Future tools will follow the same pattern (thematic, useful, free/cheap, links back to litai)

### Positioning for Outreach
- "We build small AI tools that people actually use — and we evaluate large AI systems that enterprises depend on."
- "Our free tools demonstrate the same attention to quality we bring to enterprise AI evaluation."
- The tools portfolio tells a story: "litai understands AI at every level, from consumer apps to complex system evaluation."

### SEO / Discovery Keywords
- AI translation tool, free AI assistant, PWA AI app
- Ukrainian translation app, multilingual AI tool
- Gemini API tool, OpenAI alternative, bring your own API key
